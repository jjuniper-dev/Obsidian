Here is a summary of [6 Open-Source AI Projects Trending NOW](http://www.youtube.com/watch?v=1RTq_EWv2Yo) by Matthew Berman:

Summary of the 6 Open-Source AI Projects

1. Unsloth [[00:00](https://www.youtube.com/watch?v=1RTq_EWv2Yo&t=0)]

Originally built for local LLM fine-tuning, Unsloth has expanded into a full local agent platform. It offers a ChatGPT-like UI, built-in web search, Model Context Protocol (MCP) support, remote access capabilities, and a code-free point-and-click interface for fine-tuning/training open-source models (including Qwen, Llama, and DeepSeek variants).

2. Diagram Design [[02:02](https://www.youtube.com/watch?v=1RTq_EWv2Yo&t=122)]

An open-source skill that gives AI agents the ability to generate clean, professional flowcharts, architecture diagrams, state machines, and timelines without messy overlapping connectors. It integrates into agents like Claude Code, Codex, and Hermes Agent.

3. Obsidian Skills [[03:47](https://www.youtube.com/watch?v=1RTq_EWv2Yo&t=227)]

An open skill specification allowing AI coding agents (such as Hermes, Claude Code, Codex, and Cursor) to read, write, and manage notes directly within an Obsidian vault, transforming local markdown vaults into structured long-term memory for agents.

4. Buzz [[05:07](https://www.youtube.com/watch?v=1RTq_EWv2Yo&t=307)]

A self-hostable, open-source Slack alternative created by Block (Jack Dorsey's company). It treats AI agents as first-class team members alongside human users, using a Nostr relay backend to maintain a unified, signed audit trail for all messages, reactions, and workflow executions.

5. Ego Lite [[07:23](https://www.youtube.com/watch?v=1RTq_EWv2Yo&t=443)]

A lightweight, ultra-fast browser automation tool designed to give AI agents access to your logged-in browser state without manual configuration or interference with your active workspace.

6. Modly [[08:27](https://www.youtube.com/watch?v=1RTq_EWv2Yo&t=507)]

A local, open-source AI tool that converts 2D images into 3D meshes. It is designed for lightweight desktop GPU execution, making it useful for 3D printing and asset creation for game engines.
