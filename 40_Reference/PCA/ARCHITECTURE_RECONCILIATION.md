## Core Reconciliation

The architecture evolves from:

```text
Capture → Validate → Store
```

to:

```text
Inputs → Validation → Cognitive Reconciliation → Knowledge Graph
→ Reasoning & Question Engine → Intervention & Action
→ Observed Outcomes → Feedback & Learning Update
→ Outcome Evolution
```
