# Personal Cognitive Architecture (PCA)

A structured cognitive environment built in Obsidian for long-term thinking, synthesis, learning, decision support, and agent-assisted knowledge evolution.

This repository is not primarily a note-taking system or productivity vault.
It functions as:

- a persistent cognitive environment
- a structured memory system
- a synthesis and reasoning workspace
- a human-centered augmentation layer
- a multi-domain cognitive architecture

## Core Design Principles

- Inbox-first cognitive capture
- Human-readable first
- Structured knowledge over raw collection
- Progressive trust and knowledge maturation
- Intentional linking over graph noise
- Shared architecture with segmented trust zones

## Domain Model

### Personal

Local-first unrestricted cognition:

- reflection
- learning
- ideation
- experimentation
- synthesis
- health and personal notes

### Work

Governed enterprise cognition:

- enterprise architecture
- AI governance
- strategy
- capability models
- executive outputs
- structured work research

### Shared-Knowledge

Cross-domain abstractions and reusable patterns:

- systems thinking
- cognitive architecture
- generalized governance models
- reusable frameworks
- conceptual synthesis

## Cognitive Workflow

```text
Capture
→ Distill
→ Structure
→ Relate
→ Reconcile
→ Retrieve
→ Activate
```

## Operational Philosophy

Optimize for:

- cognitive usefulness
- durable understanding
- synthesis quality
- low-friction thinking
- retrieval quality
- continuity of thought

Avoid optimizing for:

- excessive taxonomy
- maximal linking
- organizational perfection
- indiscriminate collection

## System Layer

`_System/` contains machine-oriented operational infrastructure:

- agent orchestration
- routing logic
- memory artifacts
- schemas
- workflows

Human cognition and machine state remain intentionally separated.
