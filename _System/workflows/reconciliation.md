# Reconciliation Workflow

## Purpose

Continuously evaluate new cognition against existing trusted knowledge.

## Evaluation Outcomes

| Outcome | Meaning |
|---|---|
| reinforce | confirms existing understanding |
| expand | adds nuance or capability |
| contradict | challenges current model |
| connect | links previously separate domains |
| ignore | low signal or non-durable |

## Promotion Logic

Candidate → Structured → Trusted → Canonical

Promotion should occur only when:

- retrieval value is durable
- synthesis quality is high
- concepts are reusable
- duplication is minimized
