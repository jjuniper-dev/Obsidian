# Vault Sync SOP (Working Copy + GitHub)

## Daily Workflow
1. Pull first in Working Copy (`main`).
2. Edit notes in Obsidian.
3. Return to Working Copy and review file changes.
4. Commit with clear message.
5. Push to GitHub.

## Conflict Policy
- If conflict appears, prefer resolving on desktop.
- Keep both versions temporarily if uncertain.
- Never overwrite `_System` or templates during quick conflict resolution.

## Source Policy
- GitHub-backed vault is the active sync authority.
- OneDrive capture vault is import-only unless explicitly promoted.
